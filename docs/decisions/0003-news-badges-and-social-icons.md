# 0003: お知らせのタグ別バッジとSNSアイコン

- 決定日: 2026-10-10
- 状態: ユーザー確認済み。SNSの遷移先は回答待ち
- 対象: 確認サイトのトップのお知らせと全8ページの共通フッター
- 変更元: [0002](0002-review-interactions.md)のSNS非表示方針

## 背景

追加レビューで、トップのバッジの文字・背景色を記事タグに合わせることと、問い合わせボタン下のSNS欄の復元が求められた。ユーザーはFacebook・Instagram・Xのリンク先を確認する間も実装を進める方針を選んだ。FigmaのフッターにはLINE・Instagram・Facebook・YouTube・Xの5種類がある。

## 決定

1. トップのバッジはカードの並び順から切り離し、タグに含まれる活動名から生成する。Figmaの変数に合わせてヒーローズカップは `heroes/cup-red` の `#EA0B30`、ラガールは `heroes/rugirl-pink` の `#FF4DA9`、ラグビーフェスティバルは `heroes/ragfes-yellow` の `#FFAB4B` を使う。文字は白。
2. 活動名のタグが複数あれば記事のタグ順で最初の活動名を表示する。「お知らせ」など共通タグだけの場合は活動バッジを表示しない。未定義のタグへ色や活動名を推測で割り当てない。
3. カンマ・全角カンマ・ハッシュ記号をタグの区切りとして扱い、個々のタグから一覧のカテゴリまたはキーワード絞り込みへ移動する。
4. 全8ページの共通フッターで、問い合わせボタンの24px下に5種類のアイコンを復元する。Figmaの素材・順序・寸法を使い、24pxのアイコンと16pxの間隔を基本にする。YouTubeは24×17px、Xは23×24px。
5. SNSの遷移先はユーザーの確認結果を待つ。回答前はアイコンの表示のみで、リンクや準備中ダイアログを設けない。既存公式サイトで確認できたFacebookのURLも、採用するアカウントの回答を受けてから接続する。

## 影響と保留事項

ニュースは固定データのままで、CMSとの接続は行わない。本番WordPressや別のヒーローズカップサイトは変更しない。SNS欄以外の未確定ボタンを非表示にする方針は継続する。

SNSのリンク先が届いたら各アイコンを実際のリンクへ置き換え、別タブ・リンク先・キーボード操作を検証する。LINE・YouTubeのURLも未提供のため、同様に回答後に接続する。
