# 0004: 共有デザイン調整と継続SNSの接続

- 決定日: 2026-10-11
- 状態: HTML・CSS・SNS・装飾SVG2点を実装し公開済み
- 対象: 確認サイト全8ページ
- 変更元: [0003](0003-news-badges-and-social-icons.md)のSNS接続待ち

## 背景

佐藤さんから共有されたTOP・企業/団体ページのHTMLと共通CSSを、ユーザーの依頼により取り込む。SNSは山下さんが指定した「現状SNS情報まとめ」の「継続」対象を使用する。

## 採用した変更

1. 共有CSSの文字サイズ、余白、画像位置、活動タグ、各ページのPC/SPレイアウトを反映する。前回実装したタグ連動バッジとSNSアイコンの寸法は維持する。
2. TOPの活動タグに `tags1` / `tags2`、ヒーローズカップのボタンに `cup`、日付の曜日に `copy--small` を付ける。ゴルフコンペは `other` のカテゴリ色を使用する。共有HTMLの「未来につながる一歩」も反映する。
3. 企業・団体向け支援制度の問い合わせボタンを赤へ変更する。
4. SNSのリンクを共通データに保持し、全8ページのフッターから別タブで開く。リンクには `noopener noreferrer` とSNS名の読み上げラベルを付ける。
5. LINEは一覧に遷移先の指定がないため、従来どおりアイコンの表示のみとする。

## 統合方法と補正

共有CSSと現行CSSを、共有版の元となった `b6d9849` のCSSを基準に三方向で比較・統合した。現行のバッジ色、タグ検索、SNSの寸法、フッター配置を巻き戻さず、佐藤さんの変更を反映する。生成されたHTMLを直接上書きせず、テンプレートを変更して8ページを再生成する。

幅320px・375pxの実機相当検証で、共有CSSの350px固定実績カード、団体概要表の最小幅、地図のPC最小幅がはみ出したため、カード幅をコンテナ以下に制限し、表の最小幅を画面に収め、SPの地図の最小幅を解除した。文章・スポンサーのロゴ寸法・リンク先は保持する。

共有CSSで未着手とされた年月選択と前後の記事ボタンは、既存の年月検索・前後ボタン非表示の方針を維持する。本番WordPress、GitHub権限、未確定の寄付手続きには変更しない。
