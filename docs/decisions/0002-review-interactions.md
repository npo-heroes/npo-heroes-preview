# 0002: レビューを踏まえた導線と表示の修正

- 決定日: 2026-10-10
- 状態: 承認済み
- 対象: GitHub Pagesの確認サイト8ページ
- 変更元: [0001](0001-confirmation-prototype.md)の決定6・7

## 背景

確認サイトへの23項目のレビューに、動かないボタン、写真の切り抜き、文字や装飾の差、ヘッダーと写真列の動作が含まれた。レビュー後の相談で未提供の機能を非表示にする案が示され、ユーザーが「未確定ボタンを非表示、サンプル記事は表示のみ」を選択した。

## 決定

1. 未確定のリンクを開く確認用ダイアログを廃止する。外部寄付手続き、SNS、ラガールキャンプの詳細、会計報告、追加記事読み込み、前後の記事のボタンは非表示にする。URLが確定しているスポンサー、大会、問い合わせのリンクは維持する。
2. ヘッダーの「寄付する」は `/cheers/#donation-plans` の「ご寄付プランのご紹介」へ接続する。外部寄付先は未提供のため、決済機能や外部URLを推測で追加しない。
3. ニュースの文章、日付、画像は引き続きFigmaの固定内容を使う。詳細のない記事はクリックできない表示にし、既存の本編ダイジェスト1件への導線を維持する。動画画像は静的に表示する。
4. 記事タグは一覧のカテゴリまたはキーワード絞り込みへ接続する。カテゴリ・年月・キーワードはAND条件。固定記事に該当するものがなければ0件を表示する。
5. PCとスマートフォンのメニューへTOPを追加する。ヘッダーを固定し、ページ内リンクの移動先が隠れない余白を確保する。モバイルメニューを開いた状態の寄付リンクでもメニューを閉じる。
6. 「私たちについて」「チアーズ」「企業・団体」の写真列は共通部品で連続スクロールさせる。停止・再開、ホバー・フォーカス時の停止、動きを減らすOS設定に対応する。複製画像は読み上げ対象にしない。
7. 写真の切り抜きと装飾はFigmaのデータに合わせる。実績の数字と単位を分け、見出し色、役職の中央揃え、背景写真の45%黒オーバーレイ、縦向きの英語見出し、ゴールとドット模様を修正する。

SNSの非表示方針は、[0003](0003-news-badges-and-social-icons.md)でアイコンの表示のみを復元する方針へ変更した。その他の未確定リンクの扱いは維持する。

## 比較した案と影響

共通の準備中ページへ誘導する案も提示したが、ユーザーが非表示を選択した。これによりFigmaにある一部のボタンは確認サイトに表示しない。外部寄付先、SNS、資料、未提供の記事などが確定した際は、実際に利用できる導線として追加する。

サイトのURL、8ページの構成、スポンサーのロゴサイズ、本番WordPressからの独立は変更しない。Chatの原文、添付画像、アカウント情報は公開リポジトリへ保存しない。
