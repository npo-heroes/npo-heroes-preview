# 2026-10-11: 共有HTML・CSSとSNSリンクの検証

対象: [意思決定0004](decisions/0004-shared-design-and-social-links.md)。公開前検証の記録。

## 自動検証

- `npm run check`: 型チェック、14件のテスト、8ページのビルド、ビルド後の内部リンク・画像・CSS・JS、書式チェックが成功。
- SNSの継続対象4URL、別タブ属性、LINEの表示のみ、HTML生成元の追加クラス・ボタン色・曜日装飾を検証。
- タグ連動バッジ、ニュース検索、寄付プラン、スポンサーリンクの既存テストも成功。

## ブラウザ検証

Chrome DevTools MCPでローカルの全8パスを確認。320・375・768・1024・1440・1920pxで横スクロールがないこと、SNS4リンクが共通で生成されることを確認した。PC1440px/SP375pxでは全8ページの画面を目視した。

共有CSSによる実績カードと団体概要表のはみ出し、SP地図の最小幅を補正した。TOPの見出し枠は共有CSSの意図的な-6pxの字詰めがあり、本文のはみ出しとは分けて確認する。

Instagramリンクを実際にクリックし、指定アカウント `@heroescup.news` が別タブで開いた。Facebookは「ヒーローズカップ Heroes CUP」、YouTubeは「ヒーローズカップ」、Xは `hcnews (@heroescupnews)` が別タブで開いた。指定された4アカウントへの接続を確認した。SNS自身のログイン要求は確認サイトの機能に含まれない。

モバイルメニューの開閉・Escapeでの閉鎖、寄付プランのアンカーへの移動、ニュースのカテゴリ切り替えで0件から10件への復帰も確認。スポンサー5社のPC/SPの寸法とSNS5種の画像寸法は既存指定と一致した。ローカルページのコンソールに警告・エラーはなかった。

## 保留

装飾SVG2点は原本の取得待ち。共有CSSで未着手の年月選択のデザインと前後の記事ボタンは既存方針を維持。LINEのURLは未提供。

公開結果と最終確認はデプロイ後に追記する。
